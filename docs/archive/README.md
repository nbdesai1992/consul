# Archive

Design documents from earlier versions of Consul (then Software Factory, later Shipwright). They are kept for history and describe mechanisms that have since changed: `claude -p` worker spawning, `session/spec.md` state, and the pre-board task files. The current design is in [../decisions.md](../decisions.md) and the skills under `consul/`.

- `eval-system-design.md`, `eval-implementation-plan.md`: the eval plan. The task and scoring ideas still apply; the harness details predate the brief board.
- `brief-board-design.html` / `.pdf`: the proposal that became the `briefs/` board (decision #21).
